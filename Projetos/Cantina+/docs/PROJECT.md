# Cantina+

## Visão Geral

O Cantina+ é um sistema web desenvolvido para facilitar o gerenciamento de cantinas escolares.

O principal objetivo é reduzir filas, agilizar os pedidos dos alunos e oferecer uma experiência simples tanto para estudantes quanto para funcionários e administradores.

O sistema será desenvolvido pela MV Web Lab.

---

## Problema

Atualmente muitas cantinas escolares possuem:

- Filas grandes durante o recreio;
- Pedidos feitos presencialmente;
- Dificuldade para controlar estoque;
- Poucos relatórios de vendas;
- Controle financeiro limitado.

---
## Solução

O Cantina+ permitirá que o aluno faça seu pedido antecipadamente pelo celular, informando a data e o horário do seu recreio.

Com essas informações, a equipe da cantina pré-separa os pedidos antes do intervalo. Quando o recreio começa, o aluno apenas se identifica pelo nome no balcão para retirar seu pedido já pronto.

Isso elimina o tempo de espera no preparo/pagamento e reduz drasticamente as filas no recreio.

- Gerar relatórios.
- Facilitar o pagamento.
- Tornar o sistema extremamente simples de usar.

---

## Filosofia do projeto

O Cantina+ será desenvolvido seguindo um princípio:

> Quanto mais simples para o usuário, melhor.

Nenhuma funcionalidade será adicionada se ela tornar o sistema mais complicado.

A prioridade será sempre oferecer uma experiência rápida, intuitiva e agradável.
